# Marin chart of accounts JSON

Generated from the two supplied Munis COA workbooks.

- `schemagov-entities.json`: entities that map cleanly to schemaGov (GovernmentOrganization, Program, Fund).
- `marin-accounting-dimensions.json`: Marin accounting org mappings, subprograms, and FUNC-ACT codes.
- `marin-accounting-objects.json`: accounting object/chart-of-accounts dimension.
- `meta.json`: counts, conflicts, and modeling decisions.

No COFOG/GFSM mappings were inferred. No source figures or codes were estimated.
